# 🤖 NLP-Based Intent Classification Chatbot

An intent-classification chatbot using **TF-IDF** and **Logistic Regression**, deployed with **Streamlit** for real-time interaction and session-based chat history.

## How It Works

1. TF-IDF converts user input into feature vectors.
2. A Logistic Regression model predicts the intent.
3. A matching response is returned from the intents dataset.
4. Streamlit's `session_state` keeps track of the chat history.

## Tech Stack

Python, scikit-learn (TF-IDF, Logistic Regression), Streamlit, joblib, JSON
